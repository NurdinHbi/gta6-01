Solmar City — an original 3D open-world crime game built for the make.fun gta6-01 bounty ("Make GTA 6", $1,666). Explore a procedural coastal city on foot or behind the wheel: steal cars, outrun the police across a 0–5 star wanted system, and run four story missions for the fixer Mara before free-roaming the city. Three.js renders the city (about 150 buildings, a beach, a pier, palms, traffic and pedestrians) entirely from static files with zero network requests at runtime; all sound is synthesized WebAudio. Progress saves to localStorage.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. WASD to move, Shift to run, mouse drag to orbit the camera, E to enter/exit a car, click to punch or shoot (1 fists, 2 pistol), Space for the handbrake, Esc to pause.
