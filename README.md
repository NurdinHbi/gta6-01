Solmar City — an original 3D open-world crime game in the browser. A procedural coastal city (10×10 blocks, ~150 buildings, beach, pier, lighthouse, tower, arena and marina) with a day/night cycle and golden-hour light. Walk or drive: steal cars, outrun the police from 0 to 5 wanted stars (foot cops, police cars, roadblocks and a helicopter at 4–5 stars), fight with pistol, shotgun or SMG, and run 8 story missions for the fixer Mara — including a getaway-driver escape, a bank job and a boat chase on the water. Side activities pay cash: 12 hidden packages and stunt jumps. Live 2D minimap, HUD, synthesized WebAudio sound, and localStorage saves with a Continue option. Built with vendored Three.js, static files only, no network requests at runtime.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to move, E to enter a car or the boat, M to start Mara's next mission.
